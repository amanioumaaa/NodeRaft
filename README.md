# NodeRaft

NodeRaft enables real-time, scalable distributed systems through adaptive auto-scaling and leader election within a modular framework controller.

With NodeRaft, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/NodeRaft.git`
2. `cd NodeRaft`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
